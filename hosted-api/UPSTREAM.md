# Upstream provenance

The article loader, receipt signer, sample article, x402 scheme, and SourceTag originate from https://github.com/guillebasterra/tollgate at revision `8a05527`.

The hosted API adapts that testnet flow with PostgreSQL persistence, encrypted per-session wallets, private libraries, price caps, durable idempotency, and same-origin browser endpoints. It is intentionally a testnet preview, not a production money service.
